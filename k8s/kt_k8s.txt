

vault-to-k8s-secret – Quick Start

Create one-shot Jobs that read Vault-injected KEY = VALUE files and upsert Kubernetes Secrets using kubectl (no Python/pip).

Prerequisites

Kubernetes 1.26+

Helm 3.x

Vault Agent Injector running

A Vault role that can read your secret paths (e.g., myapp-role)

Install steps (simple)

Prepare a values.yaml (example below).

Create namespace and install:

kubectl create namespace apps || true
helm install v2s ./vault-to-k8s-secret -n apps -f values.yaml


Check Jobs and Secrets:

kubectl -n apps get jobs
kubectl -n apps get secrets
kubectl -n apps logs job/v2s-vault-to-k8s-secret-s3


Update / re-run:

# edit values.yaml, then:
helm upgrade v2s ./vault-to-k8s-secret -n apps -f values.yaml







Uninstall:

helm uninstall v2s -n apps

Example values.yaml
image:
  repository: bitnami/kubectl
  tag: "1.30"
  pullPolicy: IfNotPresent

serviceAccount:
  create: true
  name: ""        # let the chart name it

rbac:
  create: true

vault:
  role: "myapp-role"  # Vault role used by the injector

# One Job per entry below
jobs:
  - name: s3
    vaultPath: "secret/data/myapp-s3"     # Vault path to read
    fileName: "s3"                        # writes /vault/secrets/s3
    k8sSecretName: "myapp-s3-secrets"     # Kubernetes Secret to create/update
    secretType: "Opaque"
    backoffLimit: 1
    ttlSecondsAfterFinished: 1800

  - name: redis
    vaultPath: "secret/data/myapp-redis"
    fileName: "redis"
    k8sSecretName: "myapp-redis-secrets"
    secretType: "Opaque"
    backoffLimit: 1
    ttlSecondsAfterFinished: 1800


Notes

fileName is just the filename (no slashes) created under /vault/secrets/; the script reads /vault/secrets/<fileName>.

The script supports single-line values per key (e.g., DB_PASS = s3cr3t). For multi-line values, switch to a stringData: YAML approach.
