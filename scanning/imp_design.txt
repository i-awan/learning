

Pod	                  Description
integration-service	Long-running worker that dequeues scan jobs from Pub/Sub, creates AquaSec CLI scanner Jobs, collects findings from pod logs, and writes results to Firestore
scan-service	REST API that receives inbound scan requests from CI/CD pipelines, resolves image tags to digests, writes the initial Firestore job record, and returns 202 with a scanId
poller-service	Periodically queries Firestore for scans in QUEUED or RUNNING state and polls AquaSec for status updates, updating Firestore when scans complete
webhook-receiver	Receives inbound HTTP POST notifications from AquaSec when a scan completes, updating the Firestore job record to COMPLETED without the need for polling
reconciler CronJob	Runs every 5 minutes to detect jobs stuck in PENDING beyond the threshold and requeues them to Pub/Sub, guarding against Pub/Sub publish failures at ingest
aquasec-db-updater CronJob	Runs every 6 hours to update the AquaSec CLI scanner's vulnerability database and write it to the shared PVC cache so scanner pods always have current CVE data without downloading it per scan
job-cleaner CronJob	Runs every 30 minutes to delete any orphaned scanner CLI Jobs older than one hour that the ttlSecondsAfterFinished mechanism failed to clean up automatically
