Below is a low-level (but still “stub / safe”) set of Wiz API interactions your Python internal scanner can implement.

Two things we can confirm from public integration docs:

Wiz exposes a GraphQL API endpoint of the form: https://api.<region>.app.wiz.io/graphql

Wiz API auth commonly uses an OAuth token endpoint that depends on your tenant IdP:

Cognito: https://auth.app.wiz.io/oauth/token

Auth0: https://auth.wiz.io/oauth/token

What’s not publicly stable is the exact GraphQL mutation name for “trigger an image scan job” in the Outpost Lite job-queue model. In practice, teams discover it via the Wiz API Explorer / “every UI action maps to a GraphQL call” approach.

So: I’ll give you a series of stub calls with placeholders for the mutation/query names, plus the exact “plumbing” (auth, GraphQL request shape, polling pattern) you can drop into your internal scanner.

Stub API call sequence (internal scanner → Wiz SaaS)
Call 0 — Resolve tenant endpoints

Inputs (config):

WIZ_API_URL = "https://api.<region>.app.wiz.io/graphql"

WIZ_TOKEN_URL = "https://auth.app.wiz.io/oauth/token" (or Auth0 variant)

client_id, client_secret (service account creds)

Call 1 — Get OAuth access token (client credentials)

POST WIZ_TOKEN_URL
Purpose: obtain a short-lived bearer token for GraphQL calls.

Call 2 — Submit a “scan request” mutation (job creation)

POST WIZ_API_URL (GraphQL)
Purpose: create a scan job for a specific image (tag or digest), and optionally specify execution environment (Outpost/cluster).

Returns:

jobId (or similar)

initial status

This is the key mutation you’ll confirm via Wiz API Explorer / vendor docs.

Call 3 — Poll job status

GraphQL query by jobId:

status (QUEUED/RUNNING/COMPLETED/FAILED)

timestamps

error info if failed

Call 4 — Fetch results/findings for that job/image

GraphQL query for findings:

vulnerability list (CVE, severity, package, fix version)

policy outcome if Wiz provides it

report URL (optional)

Call 5 — Internal scanner normalises + enforces policy

map findings → PASS/WARN/FAIL

return pipeline-compatible schema/exit code

Python skeleton (requests + GraphQL)
import time
import requests
from dataclasses import dataclass
from typing import Any, Dict, Optional

@dataclass
class WizConfig:
    api_url: str          # e.g. https://api.eu1.app.wiz.io/graphql
    token_url: str        # e.g. https://auth.app.wiz.io/oauth/token
    client_id: str
    client_secret: str
    timeout_s: int = 30

class WizClient:
    def __init__(self, cfg: WizConfig):
        self.cfg = cfg
        self._access_token: Optional[str] = None

    def authenticate(self) -> str:
        """
        Stub: OAuth client_credentials grant.
        Token URL varies by tenant IdP (Cognito vs Auth0).
        """
        resp = requests.post(
            self.cfg.token_url,
            data={
                "grant_type": "client_credentials",
                "client_id": self.cfg.client_id,
                "client_secret": self.cfg.client_secret,
                # Some tenants require an 'audience' or similar field.
                # Add it here if Wiz provides it for your tenant.
            },
            timeout=self.cfg.timeout_s,
        )
        resp.raise_for_status()
        data = resp.json()
        self._access_token = data["access_token"]
        return self._access_token

    def graphql(self, query: str, variables: Optional[Dict[str, Any]] = None) -> Dict[str, Any]:
        if not self._access_token:
            self.authenticate()

        resp = requests.post(
            self.cfg.api_url,
            json={"query": query, "variables": variables or {}},
            headers={"Authorization": f"Bearer {self._access_token}"},
            timeout=self.cfg.timeout_s,
        )

        # Handle token expiry gracefully
        if resp.status_code == 401:
            self.authenticate()
            resp = requests.post(
                self.cfg.api_url,
                json={"query": query, "variables": variables or {}},
                headers={"Authorization": f"Bearer {self._access_token}"},
                timeout=self.cfg.timeout_s,
            )

        resp.raise_for_status()
        payload = resp.json()
        if "errors" in payload:
            raise RuntimeError(f"Wiz GraphQL errors: {payload['errors']}")
        return payload["data"]

    # ---- STUBS YOU WILL WIRE TO REAL WIZ GRAPHQL OPERATIONS ----

    def create_image_scan_job(self, image_ref: str, registry: str, environment: str) -> str:
        """
        image_ref: repo:tag OR repo@sha256:digest (prefer digest for immutability)
        registry:  e.g. "nexus-prod" or hostname
        environment: e.g. "onprem-k8s-outpost-lite"
        """
        mutation = """
        mutation CreateImageScanJob($input: CreateImageScanJobInput!) {
          createImageScanJob(input: $input) {
            jobId
            status
          }
        }
        """
        variables = {
            "input": {
                "imageRef": image_ref,
                "registry": registry,
                "environment": environment,
                # optional: "priority": "HIGH"
                # optional: "correlationId": "<pipeline-run-id>"
            }
        }
        data = self.graphql(mutation, variables)
        return data["createImageScanJob"]["jobId"]

    def get_scan_job_status(self, job_id: str) -> Dict[str, Any]:
        query = """
        query ScanJob($id: ID!) {
          scanJob(id: $id) {
            id
            status
            createdAt
            startedAt
            completedAt
            errorMessage
          }
        }
        """
        return self.graphql(query, {"id": job_id})["scanJob"]

    def get_scan_findings(self, job_id: str) -> Dict[str, Any]:
        query = """
        query ScanFindings($id: ID!) {
          scanJob(id: $id) {
            id
            status
            findings {
              vulnerabilities {
                cveId
                severity
                packageName
                installedVersion
                fixedVersion
              }
            }
            reportUrl
          }
        }
        """
        return self.graphql(query, {"id": job_id})["scanJob"]

    def wait_for_completion(self, job_id: str, poll_s: int = 10, max_wait_s: int = 900) -> Dict[str, Any]:
        start = time.time()
        while True:
            job = self.get_scan_job_status(job_id)
            if job["status"] in ("COMPLETED", "FAILED", "CANCELED"):
                return job
            if time.time() - start > max_wait_s:
                raise TimeoutError(f"Scan job {job_id} did not complete within {max_wait_s}s")
            time.sleep(poll_s)

Design notes (important for your internal scanner)

Prefer scanning by digest (repo@sha256:...) to avoid tag drift.

Treat scan as async:

internal scanner returns jobId immediately OR blocks with a timeout

Add a correlationId (pipeline run ID) into the job request (if supported), so you can trace end-to-end.

Implement rate limit + retry behavior (429/5xx) with exponential backoff.

jobId, digest, status, decision
